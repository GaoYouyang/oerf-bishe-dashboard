# v107-v109：固定物理宽度、随场输运的平滑支撑通过微分同胚四级收敛门

## 一句话结论

师兄提出的“加入微分同胚原理，提高坐标变化后的泛化”现在获得了更扎实的数值基础：在同一 5 帧三维反应流、6 类光滑可逆坐标变换和 3 套九视角几何上，固定支撑区域的物理宽度、让支撑随标量场一起输运，并把硬边界改成粗网格节点完全等价的半余弦平滑边界后，场、内部梯度与观测误差在四级嵌套网格上全部严格下降。

```text
v107 = FAIL_FIXED_PHYSICAL_SUPPORT_DIFFEOMORPHIC_TRANSPORT_CONVERGENCE_V107
v108 = FAIL_TRANSPORTED_SUPPORT_DIFFEOMORPHIC_CONVERGENCE_V108
v109 = PASS_SMOOTH_SUPPORT_DIFFEOMORPHIC_CONVERGENCE_V109
independent = PASS_INDEPENDENT_RECOMPUTATION_CASE6_SMOOTH_SUPPORT_V109
numerical mechanism breakthrough = true
algorithm_breakthrough = false
```

这是一次真实的**数值机制层突破**，但还没有训练 warm initializer，也没有在未见坐标或真实 BOST 上证明泛化。

## 为什么必须重查 v106.1

v106.1 曾经得到非常漂亮的四级收敛：每一级都只清零一层边界节点，因此网格越细，这层边界在物理坐标中越薄。它可能把“边界影响逐渐消失”误写成“微分同胚输运逐渐收敛”。

v107 把边界厚度固定为一个粗网格间隔：1x 清零 1 层、2x 清零 2 层、4x 清零 4 层、8x 清零 8 层。这个单一改变立即推翻了漂亮结论：8x 场误差最坏值上升到 `0.243063`，三项完整收敛门为 `0/3`。

这不是倒退，而是排除了一个会让论文失真的替代解释。

## v108 找到了第二个问题

v107 在变换后的坐标系里重新施加同一个轴对齐硬边界。但微分同胚下，物理支撑区域应当随场一起移动，而不是每换一次坐标就重新裁成原来的盒子。

v108 删除了变换坐标系中的重新裁边和重新规范。结果显示：梯度与观测的 p90 和 worst 恢复逐级下降，8x 最坏值分别降到 `0.145674` 和 `0.035089`；但场误差在 4x 反弹，8x 最坏仍为 `0.092713`，且三项逐单元全级单调比例仅为 `26.7% / 46.7% / 33.3%`。

这说明支撑协变是必要条件，但硬边界穿过三线性插值时仍产生明显的亚网格误差。

## v109 只改了什么

v109 没有换数据、几何、形变幅度、网格、指标或阈值。唯一改动是把一个粗网格间隔内的硬跳变换成半余弦窗：

```text
w(d) = 0.5 - 0.5 cos(pi d / Delta),  0 <= d <= Delta
w(d) = 1,                             d > Delta
```

其中 `d` 是到物理边界的距离，`Delta` 是该方向的一个粗网格间隔。这个构造有三条关键性质：

1. 边界值严格为 0；
2. 第一层粗网格内部节点及更深节点严格为 1；
3. 在 2x、4x、8x 网格上按 stride 取所有粗节点，平滑窗与原硬支撑逐点完全相同。

因此粗网格三维逆问题没有被更换，变化只发生在粗节点之间的连续边界表示。

field = 0.2513

90 个比较单元中，三项的 8x 最终不劣比例均为 `100%`；三项逐单元四级全程单调比例也均为 `100%`。所有完整性门同时通过。

## 独立复算

独立程序没有导入正式 v109 数值核或 runner。它重新实现了归一化坐标半余弦窗、plateau 零均值、八角点三线性 gather、逆映射和 stride restriction，并重算全部 360 行。

| 审计项 | 结果 |
|---|---:|
| 正式行 / 独立行 | `360 / 360` |
| 逐行指标最大差 | `1.58e-14` |
| 汇总最大差 | `1.65e-13` |
| 判据布尔不一致 | `0` |
| 正式输入输出漂移 | `false` |
| 窗函数 coarse-node stride 差 | `0` |

独立路径仍共享冻结的九视角 physics kernel，因此不能声称端到端物理完全独立；但支撑、插值、restriction、汇总与判决已经独立重写。

## 这次究竟成功了什么

### 成功

- 证明 v106.1 的旧通过确实含有“支撑物理厚度缩小”混杂；
- 证明支撑区域必须随标量场一起输运，不能在新坐标系中重新硬裁边；
- 证明固定物理宽度的平滑支撑可以恢复场、梯度、观测三项完整四级收敛；
- 在不改变粗网格节点值和冻结指标的前提下，由正式与独立实现共同闭合。

### 突破边界

这是**数值机制层突破**：坐标条件模型现在不必学习一个由硬边界和插值制造的明显伪差。

它还不是算法突破，因为没有：

- observation-only learned initializer；
- 结果前封存的未见形变或未见相机几何；
- matched-accuracy 下 exact `A/A^T` 调用减少；
- fresh wall、峰值内存、curved-ray 或真实 BOST 结果。

正式边界保持为：

```text
algorithm_breakthrough = false
coordinate_generalization = false
external_generalization = false
paper_success = false
real_BOST = false
GPU training = not authorized
```

## 下一步

v109 已经授权最小坐标条件初始化器实验，但仍没有理由租 GPU。下一门将在结果前固定：

1. 输入只能使用部署可见的九视角观测、已知相机/射线几何和微分同胚参数；
2. 用连续形变参数和几何做严格留出，未见组合在训练与模型选择阶段不可见；
3. 先比较无学习、线性/RBF、小 MLP 等 CPU 级对照；
4. 每个候选都回到同一 exact `A/A^T` 与未修改 CGLS/PCGLS 精化；
5. field、完整梯度、内部梯度和观测 matched-accuracy 全部通过后，才统计调用、wall 和 RSS；
6. 只有小模型确实显示外门余量，才讨论更大的 FNO、UNO、U-Net 或租卡。

这一步才真正回答“微分同胚是否提高坐标变化后的重建泛化”，而 v109 回答的是它的离散物理基础是否可信。
