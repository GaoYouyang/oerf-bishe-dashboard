# v99：微分同胚思想先通过了“物理坐标输运门”，但还不是学习算法成功

## 一句话结论

何远哲师兄指出，先前模型只使用三种固定几何身份，没有把连续相机位姿作为输入，也没有利用群变换或微分同胚原理。v99 把这个意见落实成了一个先于训练的可证伪实验：**三维密度、梯度、射线、探测器基和伴随必须在同一个坐标变换下保持一致。**

正式程序与独立程序都通过了冻结的 11 个门。因此可以确认：我们已经具备一个数值正确的坐标输运接口，能够继续研究连续相机几何条件化。这个结果不能证明 learned warm start、未见位姿泛化、SE(3) 等变、任意微分同胚泛化、真实 BOST 或论文成功。

## 为什么先做这一步

先前 v98 允许旧九维与新四维联合变化，并用五个连续时间外折训练 mean、linear ridge 和 RBF-KRR，但最多只有 `75/90`。这说明在当前输入表示上继续堆普通回归器没有依据。

师兄的建议改变了问题本身：模型不应只记住 `geometry ID`，而应理解相机位姿、射线和坐标变换怎样共同改变测量算子。若这一层物理关系写错，再大的网络也只会学习坐标系伪差。

## 必须遵守的变换

设参考坐标为 `xi`，物理坐标为

```text
x = phi(xi),     J = d phi / d xi.
```

密度或折射率是标量场：

```text
rho_physical(x) = rho_reference(phi^{-1}(x)).
```

梯度是协向量，必须使用 Jacobian 逆转置：

```text
grad_x rho_physical = J^{-T} grad_xi rho_reference.
```

因此，只用 `grid_sample` 旋转或形变三维数组，却继续把参考梯度当成物理梯度，是错误的。BOST 前向还要求射线、探测器 `u/v` 基和积分参数与同一个映射一致。

## Stage A：离散三维刚体交换律

使用冻结的 `8 x 8 x 8`、九视角、`8 x 8` 探测器 float64 体素梯度算子，结果前固定了两种保持立方格点的三维旋转：

- 绕 `z` 轴旋转 90 度；
- `x/y/z` 循环置换旋转。

对七个预先固定的随机内场，体场、射线采样点和探测器基同时旋转，并验证：

```text
A_R T_R rho = A rho
A_R^T y = T_R A^T y
```

结果：

| 检查 | 冻结门 | 最坏结果 |
|---|---:|---:|
| forward 交换相对误差 | <= 1e-10 | `3.5528e-16` |
| adjoint 交换相对误差 | <= 1e-10 | `5.2839e-16` |
| 每个固定算子的伴随误差 | <= 1e-10 | `1.2870e-15` |

错误对照没有被“误判为正确”：

| 错误做法 | 要求中位误差 >= 1e-2 | 实际最小中位误差 |
|---|---:|---:|
| 只旋转体场，不旋转相机 | 0.01 | `1.3256` |
| 只旋转射线，不旋转探测器基 | 0.01 | `0.79165` |

## Stage B：光滑可逆剪切映射

结果前固定了一个显式可逆、行列式恒为 1 的三维光滑剪切：

```text
phi(x,y,z) = (x + 0.18 sin(pi y/2) cos(pi z/2), y, z).
```

正式程序使用 `J^{-T}` 输运梯度，并把探测器基逐采样点推前；独立程序没有复用正式梯度实现，而是从显式 `phi^{-1}` 构造物理标量场，再用自动微分直接求物理坐标梯度。

| 检查 | 冻结门 | 结果 |
|---|---:|---:|
| 逐采样点投影相对误差 | <= 1e-12 | `7.8725e-17` |
| 积分后 observation 相对误差 | <= 1e-12 | `6.7905e-17` |
| Jacobian 逆一致性 | <= 1e-12 | `0` |
| `det J` 对 1 的误差 | <= 1e-12 | `0` |
| 独立 autograd 梯度与 `J^{-T}` 交叉误差 | 审计项 | `1.6731e-16` |
| 显式逆映射往返误差 | 审计项 | `2.4148e-17` |

遗漏物理变换会产生明显误差：

| 错误做法 | 冻结下限 | observation 误差 |
|---|---:|---:|
| 省略 `J^{-T}` | >= 1e-3 | `0.06881` |
| 梯度已变换但探测器基固定 | >= 1e-3 | `0.06881` |

## 独立复算做了什么

独立 validator 没有导入正式 v99 core 或 runner。它重新实现了格点旋转、体场 pullback、相机 bundle 变换、解析场、光滑剪切、负对照、全部误差和 11 个门。

- Stage A 与正式结果的最大数值差：`8.8818e-16`；
- Stage B 与正式结果的最大数值差：`9.6958e-17`；
- 正式结果在验证前后字节不变；
- 独立物理梯度来自 `rho_ref(phi^{-1}(X))` 对物理坐标的自动微分；
- lower-level 射线、体素有限差分和插值 physics kernel 仍与正式程序共享，因此没有声称端到端物理独立。

## 这次成功了什么，没有成功什么

**真实成功：**

- 把师兄的建议变成了可运行、可失败、已独立复算的物理门；
- 证明完整坐标输运在两个离散三维旋转和一个光滑剪切族上达到数值舍入精度；
- 证明只变三维数组、只变射线或漏掉 Jacobian 都会产生数量级明显的错误；
- 为后续把连续相机 pose/ray 参数输入模型提供了可信接口。

**尚未成功：**

- 没有训练任何新 initializer；
- 没有证明连续未见相机位姿泛化；
- 没有证明完整 SE(3) 等变；
- 光滑剪切使用逐采样点 pushed-forward basis 和参考参数积分，没有证明固定物理相机在一般非刚体映射下等价；
- 没有外部数据、真实 BOST、wall/RSS 或论文性能结果。

所以当前判决仍是：

```text
coordinate_transport_implementation_gate = passed
algorithm_breakthrough = false
paper_success = false
```

## 下一道真正改变算法判断的门

下一步不再输入三个离散 `geometry ID`，而是输入每个视角的连续几何：相机原点/方向、探测器 `u/v` 基、内参与射线参数。公平比较：

1. 固定 geometry ID；
2. 连续 pose/ray encoding；
3. 映射到参考坐标系后的 canonical observation；
4. 只做数据旋转、没有物理输运的错误对照。

实验采用 `leave-one-geometry-out`：整套相机几何从拟合中拿走，只用部署可见 observation 和标定参数预测 warm start。只有容量门和严格 observation-only 小模型都通过，才授权一个最小 pose-conditioned sentinel；现在仍不需要租 GPU。

## 与已有工作的关系

- [Geo-FNO](https://www.jmlr.org/papers/v24/23-0064.html)把不规则物理域变形到规则潜在网格，但它不直接解决 BOST 相机测量算子的变换。
- [Diffeomorphism Neural Operator](https://www.nature.com/articles/s42005-024-01911-3)把不同物理域映射到共同域并显式输入几何信息。
- [DIMON](https://www.nature.com/articles/s43588-024-00732-2)在统一参考域上学习经微分同胚参数化的几何依赖算子，并强调标量、向量和张量需按各自群作用输运。
- [EqGINO](https://arxiv.org/abs/2606.03260)区分了离散网格对称性的精确等变与连续方向的经验泛化；这也正是 v99 不把两个格点旋转写成完整 SE(3) 证明的原因。

这些论文支持“参考域 + 几何条件”这一原则，但不能替我们的 BOST forward/adjoint、相机标定与真实实验背书。
