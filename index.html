工程意义

快速起步，物理收尾，危险时退回标准解

降低批量重建成本

高速反应流会产生连续帧和多视角数据。每帧少一次完整 forward / adjoint，收益会随实验批次持续累积。

保留物理可解释性

学习模块只生成起点，最终解仍由显式成像模型和经典 Krylov 求解器精化，便于诊断误差来源。

让局部失效可见

Case 6 证明平均场变好不等于内部梯度安全。逐单元八门能直接暴露会损伤火焰局部结构的候选。

未来期许和方向

只扩展证据指出的缺失结构

研究路线由最新负证据驱动，而不是由模型名、算力规模或已经投入的时间驱动。

最近科学门

K20 与当前固定深度 global reference 加深路线已关闭。只有新的物理信息，或一个物理上真正不同、结果前唯一冻结且可证伪的机制，才能继续；不得再调深度、容差、全局低秩或既有 global-quadratic 家族，也不训练大模型、不启动 wall/RSS。

何时租 GPU

现在仍不租：当前固定迁移假设已被前瞻门否定，训练吞吐不是阻塞。只有物理上不同的机制先通过 matched-accuracy 与便宜对照，且 CPU 实测证明训练吞吐是主要瓶颈，才重新评估 GPU。

何时接组内数据

公开独立工况通过后，接入位移图、相机内外参、视角定义、重复测量噪声、现有重建接口和认可基线。
