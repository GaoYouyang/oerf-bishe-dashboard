Post-open diagnosis

乘大 correction 也修不好

外部门判完之后，BLASTNet phi=0.5 已经是开发数据。后验扫描只用于找失败原因，不能回写正式分数，也不能再称外部泛化。

幅度确实偏小

沿冻结 correction 方向扫描 alpha in [0, 2]，四帧的 observation 最优 alpha 为 1.4, 1.4, 1.4, 1.2。原始 alpha=1 没走够。

但方向仍不够

调到 observation 最优幅度后仍是 0 / 4 同时过三门；三帧 observation 仍失败，四帧 gradient 都越过兼容界。

机理判决： POST_OPEN_CORRECTION_SPAN_INSUFFICIENT_FOR_OBSERVATION_GATE。下一版不能只学习一个增益，而要改变可用修正方向，并让方向感知物理尺度、密度梯度频谱和部署可见残差。
What changed

这次负结果真正淘汰了什么

最有价值的不是继续给旧模型加层，而是把错误假设从候选集中删掉。

已淘汰：零适配平移

PoolFire 上的 SARC 不能原封不动迁到这个 H2-air DNS，并继续满足同精度门。

已淘汰：单标量修复

沿同一个 correction 方向做最优调幅，仍无法消除 gradient/observation 冲突。

保留：多方向尺度校准

下一候选必须从 observation 中选择多个低保真修正方向，并以另一个开发工况训练。

当前最窄、最有信息量的算法问题已经变成：能否用部署可见的残差频谱和视角不平衡，组合多个 correction basis，在不读取 truth 的前提下同时守住 field、gradient 与 observation？这比继续扩大同一 SARC 网络更值得计算。
